# ModTheSpire.jar 下载说明

由于 GitHub 下载链接不稳定，你需要手动下载 ModTheSpire.jar：

## 下载方法

### 方法1：从 GitHub Releases 下载
1. 访问：https://github.com/kiooeht/ModTheSpire/releases
2. 找到最新的 release（例如 v3.6.3）
3. 下载 `ModTheSpire.jar`
4. 放到本 `libs/` 文件夹

### 方法2：从 Steam Workshop 下载
1. 访问 Steam Workshop：https://steamcommunity.com/sharedfiles/filedetails/?id=1605833019
2. 订阅 ModTheSpire
3. 从 Steam 库中找到 ModTheSpire 的文件位置
4. 复制 ModTheSpire.jar 到 `libs/` 文件夹

### 方法3：使用备用链接
如果上述方法都不行，尝试这些备用链接：
- https://github.com/kiooeht/ModTheSpire/archive/refs/tags/3.6.3.zip
- 解压后找到 ModTheSpire.jar

## 文件信息

- 文件名：`ModTheSpire.jar`
- 大小：约 100 KB
- 位置：`libs/ModTheSpire.jar`

## 验证

下载后，确保 `libs/` 文件夹中有以下3个文件：
- ✅ `BaseMod.jar` (约 1.3 MB)
- ✅ `ModTheSpire.jar` (约 100 KB)
- ✅ `desktop-1.0.jar` (约 100 MB，你上传的)
